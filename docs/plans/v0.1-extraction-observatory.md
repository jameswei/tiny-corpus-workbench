# v0.1 — Extraction Observatory

## Outcome

v0.1 established a local, service-free observation workflow for one source.
Docling and MarkItDown process the same private byte snapshot independently.
The observation preserves source identity, extractor evidence, and a
deterministic descriptive comparison.

Lossless `DoclingDocument` JSON is the canonical extracted representation.
Docling Markdown and MarkItDown Markdown are separate derived views. The
comparison describes observable differences. It does not rank extractors or
claim semantic equivalence.

## Rationale and boundaries

The milestone made extraction inspectable before adding diagnosis or repair.
It publishes each observation atomically in a new directory and provides
read-only verification. Hashes and recorded provenance make ordinary local
tampering detectable under the trusted-local model.

The project-authored fixture set contains three document families in PDF,
DOCX, Markdown, and text: twelve controlled fixtures in total. Extraction runs
offline with pinned dependencies. PDF models are prefetched explicitly; an
observation does not download them.

v0.1 did not add diagnosis, repair, approvals, prepared revisions, batch
processing, a browser or service interface, or downstream RAG work. Original
sources and raw extractor artifacts remain unchanged.

## Validation outcome

The released workflow verified deterministic fixtures, independent extractor
attempts, canonical JSON round trips, immutable publication, failure evidence,
and read-only integrity checks across the four supported formats.
