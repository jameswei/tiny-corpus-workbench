# v0.2 — Evidence-Based Diagnosis

## Outcome

v0.2 added local diagnosis of one verified observation. Diagnosis reads only
the canonical `DoclingDocument` and publishes a separate immutable record with
deterministic, evidence-backed findings.

Eight fixed rules formed the milestone ruleset. Findings use stable document
references and compact evidence instead of copying arbitrary source passages.
An independent verifier checks artifact integrity and can compare the
diagnosis with its observation and deterministic derivation.

## Rationale and boundaries

Diagnosis was separated from extraction so that a finding could remain an
observation, not an instruction to mutate a document. MarkItDown remains a
descriptive comparison view and does not produce findings.

The milestone preserved the source, observation, and raw extraction artifacts.
It did not add repair, approvals, prepared revisions, batch execution, a
browser or service interface, semantic correctness claims, extractor ranking,
or downstream RAG work.

## Validation outcome

The released workflow verified all eight rules, stable identifiers and
ordering, source-text-free evidence, atomic diagnosis publication, independent
verification, hybrid diagnostic fixtures, and unchanged observation records.
