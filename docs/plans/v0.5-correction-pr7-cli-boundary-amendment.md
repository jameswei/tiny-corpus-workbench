## Scope

This amendment supersedes only the PR 7 requirement at original plan lines
1200–1202. That requirement said that a normal-use `uv run --frozen` example
must make the current-document validator fail.

All other PR 7 requirements, exclusions, validation, and acceptance criteria
remain in force.

## Correct boundary

The `corpus` CLI validates only the arguments that follow its console-script or
module entry point. The CLI does not own or interpret the command that launches
it.

`uv` is a source-environment launcher. Its options, groups, Python selection,
and command ordering are outside the `corpus` CLI contract. The project must
not add uv or shell parsing to the CLI, the current-document policy validator,
or its tests.

The current-document policy validator continues to reject stale active command
names such as `tcw` and `inspect-corpus`. It does not validate `--frozen`,
`uv run`, shell segments, or launcher option order.

## Documentation and environment use

- Repository examples can use `uv run corpus ...`.
- An activated virtual environment can run `corpus ...` directly.
- Setup and CI can use frozen uv commands.
- These choices describe the source environment and documentation style. They
  do not define CLI semantics.

Reviewers must reject requests to parse or allowlist uv or shell syntax as part
of PR 7. A future documentation-style lint would require separate owner
approval and a contract that does not broaden the CLI boundary.
