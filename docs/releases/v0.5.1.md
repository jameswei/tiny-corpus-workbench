# v0.5.1 — Document Policy Cleanup

v0.5.1 is a source-only corrective patch for v0.5.0.

## Correction

- Remove the current-document natural-language policy validator.
- Remove tests that bound documentation and historical evidence to CI.
- Remove the validator from the Fast CI job.
- Keep CLI command, schema, fixture, and Workbench behavior unchanged except
  for version reporting.

README, CURRENT, release notes, learning text, site copy, and ledgers remain
documentation and evidence. Reviewed and approved plans, plus explicit owner
amendments, govern implementation.

The v0.5 Local Visual Workbench and pre-release amendment behavior remain as
described in the [v0.5.0 release note](v0.5.0.md).
